# SQL-PROJECT-Employee-Analytics-Payroll-System
SQL-based Employee Analytics Payroll project showcasing database design, CRUD operations, aggregate queries, subqueries, joins, and window functions like RANK, DENSE_RANK, and LAG to analyze salary trends, department insights, and employee data for real-world business analytics scenarios.

## Overview
This project demonstrates SQL skills for managing employee data and performing payroll analytics. It includes database design, data manipulation, and advanced analytical queries.

## Features
- Employee database creation  
- CRUD operations  
- Aggregate queries & filtering  
- Subqueries and joins  
- Window functions (RANK, DENSE_RANK, LAG)

## Tech Used
- MySQL  
- MySQL Workbench  

## Purpose
Built as a mini project to showcase practical SQL and data analytics concepts used in real-world scenarios.
